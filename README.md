## Fondements Textuels de Référence

La procuration pour les actes de pèlerinage est attestée par les textes fondateurs de la Sunnah prophétique :

1. **Sahih Al-Bukhari (n°1513) & Sahih Muslim (n°1335)** : Hadith de la femme de Khath'am sollicitant le Prophète (ﷺ) pour accomplir le pèlerinage au nom de son père âgé.
2. **Sounan Abi Daoud (n°1811)** : Hadith de Shubrumah établissant l'obligation préalable pour le mandataire d'avoir accompli sa propre Omra avant d'agir au nom d'un tiers.
